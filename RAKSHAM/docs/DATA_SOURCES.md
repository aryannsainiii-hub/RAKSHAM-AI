# Data sources

The only active source in this version is a small built-in synthetic fixture. It is labelled synthetic in API responses, dashboard banners, and CSV rows. Fixture retrieval/epoch metadata is generated locally.

CelesTrak public GP TLE/OMM support is planned but not connected. Refresh therefore returns HTTP 503 and status reports that no provider is configured. No external records, retrieval schedule, cache, or source accuracy are claimed.
